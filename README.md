# AMRP

A utility tool for patching AMMB Merchant Reports.  

![AMRP](res/icon.png)  

## Quick Start

### Build
Building from source code requires Go version 1.25.5 or later, the Fyne framework, the Fyne CLI tool, and SHA256Sum to generate checksums. For windows builds, UPX is required for compression.  

> [!NOTE]  
> On Windows, the MSYS2 (with MinGW) environment is required to run the build.  

Run the build script to generate the executable binary.  

- `build.sh` for linux  
- `mingw-build.sh` for windows
